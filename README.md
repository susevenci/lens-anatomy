# 拆镜 · 一支 50mm f/1.4 的内部，和它如何决定你的照片

一个纯前端的光学交互教具：把一支 50mm f/1.4 定焦镜头逐层拆开，切到光路模式拖动光圈，在同一帧里看见镜片开合、光锥收窄、景深数值变化、散景虚化变化。

> **在线体验**：<https://lens-anatomy.app.workbuddy.host/?sharecode=RLU23IM7HJ>

---

## 它想解决的问题

摄影教程里"光圈越小，清晰范围越大"这句话，几乎所有人都会背，但很少有人真的"看见"过。原因很简单：光圈在镜头内部，景深在取景器里，两者隔着十几片玻璃和一个机身，没法同时观察。

这个作品把它们放进同一帧。拖动光圈滑块，四件事同时发生：

1. **9 片叶片**实时改变围成的九边形孔径
2. **光锥收窄**，被叶片挡住的外缘光线变成红色虚线，在光阑处截断
3. **景深尺**上清晰区间实时伸缩，显示具体毫米数
4. **散景面板**里三个不同距离的点光源各自弥散，0.50m 处永远锐利

从 f/1.4 到 f/16，景深从 **8.4 mm** 变成 **96.0 mm**，11.4 倍。

## 功能

| 模块 | 说明 |
|---|---|
| 五层拆解 | 外观层 → 机械层 → 光学层 → 镀膜层 → 像面层，滑块驱动，外层向外淡出 |
| 结构模式 | 3D 镜筒，拖拽旋转（yaw ±35°、pitch ±20°，带阻尼），悬停零件联动右侧标注卡片 |
| 光路模式 | 正交侧视剖面，平行光自左侧射入，逐面折射后汇聚于像面 |
| 光圈盲测 | 一道四选一，复用散景渲染，答错也有收获，可跳过 |
| 色差彩蛋 | 拆到 L5 后可选开启，白光分解为红绿蓝三条路径，在像面边缘不共焦 |

```
├── app.js          光学计算、场景构建、交互
└── three.min.js    three.js r147（本地化，MIT）
```

### 光学处方是解出来的，不是抄的

7 片 6 组、14 个折射面，需要在满足物理合理性的前提下，让平行光精确汇聚在像面上。约束相互冲突，是无法手工调出的：

- 系统焦距锁定在 50 mm
- 每个面 `|R| ≥ 1.3r`，避免球面在通光半径内不可解
- 每个元件边缘厚度为正（薄的正透镜会自相交）
- 元件符号模式必须符合双高斯：前组「正-负-正」，后组「负-正-双胶合-正」

用带符号约束的坐标下降求解 14 个面曲率。结果：放大率 A = 0.8404，f/1.4 入射半高 21.25 mm，各面光束占空比最大 0.883（不会穿出镜片边缘）。

### 光线是近轴追迹，不是动画

每条光线在 14 个面上按 `n₁·sinθ₁ = n₂·sinθ₂` 的近轴形式逐面折射，交点位置由球面矢高公式求得。散开状态下追迹用的是**位移后的实际面位置**，所以镜片飞散时光线依然正确汇聚。

通过光线恒为 9 条并按当前光圈的入射半高铺开——如果按固定高度画，f/16 时会被光阑截得只剩一条中线，"光锥收窄"这个核心表达直接消失。

### 景深用真公式

```
超焦距   H  = f² / (N · c) + f
景深近限 Dn = H · s / (H + s)
景深远限 Df = H · s / (H − s)
c = 0.03 mm（全画幅容许弥散圆）, f = 50 mm, s = 500 mm
```

| 光圈 | 超焦距 | 景深范围 | 景深总长 |
|---|---|---|---|
| f/1.4 | 59.57 m | 496.2 – 503.8 mm | 8.4 mm |
| f/16 | 5.26 m | 456.6 – 552.6 mm | 96.0 mm |

## 本地运行

纯静态站点，任意静态服务器即可。**不要用 `file://` 直接打开**，浏览器会拦截 `three.min.js` 的加载。

```bash
cd app
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

也可以用任意静态托管（GitHub Pages / Netlify / Vercel），把 `app/` 作为站点根目录即可。

### 深链接参数（便于截图与分享）

```
?open=0        跳过开场动画
&dis=62        拆解进度 0–100
&f=16          光圈（吸附到最近 1/3 档）
&mode=ray      直接进入光路模式
&ca=1          开启色差
```

例：`index.html?open=0&dis=100&mode=ray&f=1.4`
